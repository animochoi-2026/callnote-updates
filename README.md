# 통화노트 업데이트

Android 통화 녹음 검토·요약 앱의 설치 파일과 변경 안내입니다.

앱 **설정 → 앱 업데이트 · 최신 / 현재 / 이전**에서 버전을 선택하세요. 처음에는 Releases의 최신 APK를 설치합니다. 앱을 삭제하지 말고 기존 앱 위에 설치하세요.

- 최신: 가장 최근 배포한 기능 버전
- 현재: 이 휴대폰에 설치된 버전. 최근 3개에 포함되면 재설치 가능
- 이전: 보관 중인 다른 이전 버전으로 롤백
- 현재가 최신이면 같은 버전 번호가 두 항목에 표시됩니다.
- 최초 제공 버전은 1.4.0과 1.3.4입니다. 이후 최대 3개 기능 버전을 유지합니다.

이전 기능의 APK도 최신 배포 묶음과 같은 설치 번호로 다시 서명합니다. 따라서 Android에서 앱을 삭제하거나 데이터를 초기화할 필요 없이 버전을 전환할 수 있습니다. 모든 APK의 서명은 같아야 합니다.

릴리스 게시 시 자동 정리가 실행됩니다. 최신 `catalog.json`에 포함된 최근 3개 버전만 보관하고, 범위 밖 릴리스·버전 태그와 과거 릴리스에 남아 있는 오래된 APK를 삭제합니다. 이 저장소에는 앱 소스나 사용자 기록을 올리지 않습니다.

Claude는 Gemini 또는 OpenAI로 인식한 전사문을 요약합니다. Claude API 키가 별도로 필요하며 API 요금이 발생합니다. 키는 휴대폰에서 직접 입력합니다.

설치 후 기존 기록·설정이 유지됩니다. 신규 설치에서는 본인의 녹음 폴더·Google Sheets·API 키를 설정하세요.
